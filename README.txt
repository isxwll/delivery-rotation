GB SERVICE SOLUTION INSTALLATION — DELIVERY ROTATION

Versão de interface refinada para celular.

- Interface em português brasileiro; nome Delivery Rotation e marca GB permanecem em inglês.
- Início do projeto configurado para 19/10/2026.
- Candidaturas abrem às 07:00 e fecham às 14:00, fuso Europe/London.
- Candidaturas são limpas automaticamente à meia-noite; pontos acumulados não são zerados.
- Navegação: Candidatos, Lista de prioridade e Team Points.
- Pontuação inicial atualmente carregada do rascunho anterior. Os valores precisam ser confirmados, pois a tabela interativa não foi preenchida com valores definitivos.
- Datas da última delivery estão como desconhecidas, pois não foram fornecidas.

IMPORTANTE: esta versão estática usa armazenamento local do navegador (localStorage). Os dados não são compartilhados entre celulares. Antes de usar como controle oficial da equipe, é necessário conectar um banco de dados compartilhado e proteger o registro de deliveries. O GitHub Pages sozinho não fornece banco de dados.

Publicação: substitua index.html e mantenha gb-logo.png na raiz do repositório delivery-rotation. Faça commit na branch main. O GitHub Pages publicará a nova versão após o deploy.
